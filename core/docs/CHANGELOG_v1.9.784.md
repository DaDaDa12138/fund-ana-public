# CHANGELOG v1.9.784 — GitHub Actions 日更与正式报告仓库存储

**发布日期**: 2026-11-08

## 本轮修改

- 新增 Actions 定时及人工入口，通过专用自托管 Runner 调用现有调度器单次执行，不改变采集接口、金融规则和原子发布协议。
- 按正式指针及原 manifest 校验，限定导出正式榜、累计跟踪和前瞻展示文件，拒绝未提交、损坏、越界及混入材料。
- 报告写入同仓库独立 daily-reports 分支，同一修订不可变且幂等；执行失败仅保存失败收据，保留旧正式报告。
- 原始采集日志留本机，Runner 使用专用账号和参数受限的运维入口；临时导出和本地执行日志有独立保留期。

## 验证范围

隔离回归覆盖正式身份、SHA、缺失与损坏、允许清单、重复执行、失败保旧、调度终态和自动化材料保留。自然定时任务验收单独登记，人工触发不能替代自然任务验收。
